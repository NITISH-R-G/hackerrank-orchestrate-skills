# Release Gate Checklist

Copy into your repo. Every line is `[ ]` until a command has printed the proof.
Cite the command, not your memory.

Ordered so the cheap checks that catch the most catastrophic defects run first.

---

## 0. Before anything — is what you're testing what you'd ship?

- [ ] `git status --porcelain` is empty for tracked files
- [ ] Every generated artifact regenerated **to a temp path** and hashed against
      the committed one *(P16 — artifacts are stale by default)*
- [ ] The artifact was generated by the **current** commit, not three commits ago
- [ ] Clone to an empty directory and run following **only your README**
      *(P15 — this is where "works on my machine" dies)*
- [ ] Each test file passes **in isolation**, not only as a suite *(P10)*

> Two real defects that only this section catches: a repository whose clone
> contained 2 source files, and a `pytest` invocation that aborted the whole
> suite on a stale script.

## 1. Correctness

- [ ] Every explicit requirement checked **literally**, with constants
      transcribed from the spec — not imported from your own code
      *(otherwise you are only proving the code agrees with itself)*
- [ ] Output schema: exact field names, exact order, exact separators
- [ ] Value domains: every emitted value is in the allowed set
- [ ] One output per input, in input order, no duplicates
- [ ] Edge cases: empty, missing, malformed, oversized, wrong-encoding

## 2. Evidence for every change since the last release

For each change:

- [ ] Metric named **before** the change was written *(P1)*
- [ ] Gain measured, **and cost measured**
- [ ] Blast radius counted — how many outputs changed *(P2)*
- [ ] Counterfactual proven where a component is claimed to matter *(P3)*
- [ ] Ceiling computed — was a gain even possible? *(P4)*
- [ ] Rejected alternatives logged with the number that killed them *(P5)*

## 3. Trust the tests

- [ ] Negative control for each audit: break the property, confirm it screams *(P6)*
- [ ] No audit writes to a path it also reads as ground truth *(P7)*
- [ ] Run the full suite, then **diff every artifact** — anything that changed,
      a verifier wrote to
- [ ] Benchmarks measured **inside** the real operating envelope *(P8)*
- [ ] Unstable metric? Suspect the metric before the code
- [ ] Tests hermetic: credentials/network cleared by an autouse fixture *(P10)*

## 4. Regression

- [ ] Golden hash of full output pinned
- [ ] Re-pin log records **cause, effect, why-right, score** for every change *(P9)*
- [ ] Golden pinned to the **deterministic** configuration, not one that varies
      with the environment
- [ ] Every fixed defect has a test that fails without the fix

## 5. Robustness to unseen data *(P12)*

- [ ] IDs renamed to a different scheme → decisions survive
- [ ] Timestamps reformatted (day-first) → ordering survives
- [ ] Every context file shuffled → output survives
- [ ] Directory/file names changed → resolution survives
- [ ] File types detected by **magic bytes**, never extension
- [ ] Lexicon terms firing on exactly **one** sample row reviewed as suspects
- [ ] `CONSTANTS.md` exists with a **provenance** column *(P13)*

## 6. Determinism

- [ ] Repeated runs, multiple processes, multiple hash seeds → one hash
- [ ] No `random`/`uuid`/`time`/`hash()`/`glob` reaching output; adjudicated
      exceptions recorded **in the scanner**, not in your head
- [ ] The boundary is stated: exactly where determinism stops and why *(P11)*

## 7. Security

- [ ] Injection: prompt, control tokens, CSV formula, unicode/homoglyph, RTL
- [ ] Regex: catastrophic backtracking on adversarial input; quantifiers bounded
- [ ] Path traversal; archive entries relative and contained
- [ ] Every failure path degrades to a valid output, never a crash
- [ ] No secrets in repo, history, artifacts, or logs
- [ ] Malformed/missing/corrupt/wrong-MIME inputs all handled

## 8. Documentation *(P17)*

- [ ] Every number in the README verified today
- [ ] No recommended command disables a required capability
- [ ] Limitations stated **before** anyone asks *(P19)*
- [ ] Claims labelled: verified / measured / inference / unknown *(P18)*

## 9. Stop condition *(P20)*

- [ ] Everything fixable is fixed and re-verified, **or**
- [ ] The remaining uncertainty is named **precisely** — what information is
      missing, and why it is absent rather than merely unexamined

---

## Final verdict

Exactly one, no hedging:

**READY** — every box has a command behind it
**NOT READY** — with the specific blocker named
